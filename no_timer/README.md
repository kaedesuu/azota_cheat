# no_timer
> [!note]
> - description: makes time infinite so you can submit the answer at anytime. **(NOTE: if teacher stops the test or close it, you won't be able to submit the answer, so DON'T USE this in a serious test/exam).**
> - usage: just install the tampermonkey script and take the test

To install the script, you need to:
1. install tampermonkey
2. click on the raw link: 
3. press `Install`

## structure
- [./no_timer.js](./no_timer.js): the main file, not minified.
- [./no_timer.user.js](./no_timer.user.js): use for tampermonkey userscript.
